# Results & benchmarks

Every number in this project comes out of the from-scratch harness — its own
CLEAR-MOT / IDF1 / HOTA implementation (cross-checked against `trackeval` to
1.4e-3), paired significance testing, seed variance, and a config hash on every
run. Nothing here is copied from a paper's results table.

## Read the reports

The benchmark reports are published as pages on the site. Each one carries the
full leaderboard, the paired Δ against the baseline with Wilcoxon p-values, and
the ID-switch error taxonomy for that dataset.

| Report | What it measures |
|---|---|
| [synthetic](https://visiontrack.hulage.in/benchmark) | controlled scenes with known ground truth — the fastest signal, no download needed |
| [DanceTrack](https://visiontrack.hulage.in/benchmark/dancetrack) | non-linear motion **and** near-identical appearance, perturbed-GT (oracle) protocol |
| [DanceTrack · real YOLOX](https://visiontrack.hulage.in/benchmark/dancetrack-yolox) | the same dataset with real detections, so detector quality is part of the measurement |
| [SportsMOT](https://visiontrack.hulage.in/benchmark/sportsmot) | fast non-linear motion with *distinguishable* appearance — the decoupled RQ2 test |

## Why there are no `results_*.md` files in this repo

The markdown result tables are **generated artifacts**, regenerated by
`make reproduce` and the `experiments/` entry points, so they are gitignored
alongside the parquet files they are derived from (see `.gitignore`). Committing
them would mean a churning diff on every rerun for content that is reproducible
by construction.

That is deliberate, but it had a consequence worth naming: the docs nav used to
list eight `results_*.md` pages that were never part of the published build, so
each one returned a 404 on the deployed site. This page replaces that section —
it points at the reports that actually exist, and tells you how to build the
markdown yourself.

## Regenerate them locally

Every report is one command. The markdown lands in `docs/`, the HTML in `web/`:

```bash
# synthetic — no dataset download required
python -m experiments.benchmark --out-md docs/results_benchmark_synth.md

# a real dataset (requires the cached sequences; see SPORTSMOT.md / the README)
python -m experiments.benchmark --dataset sportsmot \
    --out-md docs/results_benchmark_sportsmot.md \
    --out-html web/benchmark-sportsmot.html
```

The standalone error taxonomy runs the same way:

```bash
python -m experiments.error_taxonomy --dataset sportsmot --preset bytetrack
```

For the full reproduction path — including which caches to build first — see
`make reproduce` in the README and the dataset recipes
([`SPORTSMOT.md`](SPORTSMOT.md)).
