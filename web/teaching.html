For developers

From pip install to your own video.

VisionTrack is a real, installable tracker — not a wrapper. The whole association core (an 8-state Kalman filter, an O(n³) Hungarian solver, ByteTrack two-stage matching, and a tentative→confirmed→deleted lifecycle) is written from scratch on NumPy, with zero tracking libraries. The metrics harness (CLEAR-MOT / IDF1 / HOTA) is from scratch too, cross-checked against trackeval to 1e-3, with paired significance tests and config hashing — so results are reproducible, not vibes.

Quickstart

  1. Install

    The core is NumPy-only. pip install visiontrack-mot — add the [video] extra to run on real mp4s.

  2. Feed it detections, get stable ids back

    Bring any detector (its boxes are all VisionTrack needs); it returns one confirmed, numbered track per object, held across frames. See the snippet below.

  3. Run it on a real video or a live camera

    visiontrack track in.mp4 out.mp4 --model yolox_nano.onnx annotates a file; visiontrack webcam runs the same pipeline on a live camera.

  4. Reproduce the study

    visiontrack demo prints metrics on a synthetic scene; make benchmark runs the significance-tested leaderboard. Or open the browser demos — no install at all.

The core loop, in full

# pip install visiontrack-mot
import numpy as np
from visiontrack import ByteTracker, TrackerConfig, Detection

tracker = ByteTracker(TrackerConfig())

# your detector yields (boxes, scores, class_ids) per frame
for boxes, scores, class_ids in detection_stream:
    dets = [
        Detection(xyxy=b, score=s, class_id=c)
        for b, s, c in zip(boxes, scores, class_ids)
    ]
    for obs in tracker.update(dets):          # -> list[TrackObservation]
        # obs.track_id stays fixed for the same object across frames
        print(obs.frame, obs.track_id, obs.xyxy, obs.score)

That's the whole public contract: build Detections, call update() once per frame, read track_id off each TrackObservation. Full reference in the docs and the write-up.

What runs inside update()

  1. Predict

    Every existing track advances one step through its 8-state constant-velocity Kalman filter (position + aspect + height, and their velocities).

  2. Associate — high scores first

    ByteTrack round one: confident detections are matched to predicted tracks by IoU via the Hungarian solver, inside a χ² gate.

  3. Associate — recover the rest

    Round two gives unmatched tracks a second chance against the low-score detections — the trick that carries objects through a brief occlusion.

  4. Manage lifecycle

    A tentative→confirmed→deleted state machine spawns an id only after a few consistent hits and retires tracks gone too long — so an id you see is a committed one.

For everyone

What is object tracking — and why is it hard?

Imagine watching a security camera over a busy shop. A computer can already look at a single frame and point at things: "that's a person, that's a person, that's a cart." That part is called detection. But it has no memory — in the very next frame it points again and has no idea it's the same people.

Tracking is the memory. It gives each person an invisible name tag — #3, #4, #5 — and keeps that tag stuck to the same person as they walk around, turn, and pass behind a shelf. Get that right and suddenly you can answer real questions: how many different people came in (not how many times the camera blinked), how long each one stayed, which way traffic flowed.

The party analogy Detection is glancing at a crowded party and noting "there are twelve people here." Tracking is recognising that the person by the door is the same person who was at the snack table a minute ago — so you don't count them as two guests. VisionTrack is the part that keeps everyone's name straight, even when they cross paths or briefly step out of view.

Why is it hard? People and cars look alike, they cross over each other, and they disappear behind things and reappear. A good tracker has to guess where each one is heading, match the new sightings to the right tag, and not panic when someone vanishes for a moment. VisionTrack does this with a bit of physics (predicting motion) and careful matching — all built from the ground up, and all running on your own device, with nothing uploaded.

In three steps

  1. Spot

    Each moment, find everything of interest in the picture.

  2. Guess

    Predict where each already-known thing probably moved to.

  3. Match & remember

    Line up the new spots with the guesses, keep every name tag attached, and hand out a new tag only for someone genuinely new.

A few words you'll hear

Detection — "what's in this frame?"
Finding objects in one still image, with no memory of before or after.
Track / ID — "the name tag"
One object's identity, kept the same across every frame it appears in.
ID switch — "the mix-up"
When the tracker accidentally swaps two objects' tags. Fewer is better.
Occlusion — "hidden for a moment"
When something passes behind another object and briefly can't be seen.
On-device — "stays on your computer"
The video is processed right where you are; nothing is sent to a server.
