# Counting paper — manuscript source

*When recovering more tracks creates false counts: A controlled study of track
initiation and line-crossing counts.* Rushikesh Hulage, November 2026.

- `visiontrack-counting.tex` — the three-page manuscript.
- `initiation-threshold.pdf` — Figure 1, regenerated from the replay outputs
  (see [Regenerate Figure 1](../docs/COUNTING_PAPER_OUTLINE.md#regenerate-figure-1)).

Build the PDF with any LaTeX engine, for example:

```bash
tectonic visiontrack-counting.tex
```
